# FabricMind 小程序简单版功能说明

## 目标

先不接入老师的本地换色模型，只做一个能演示的 AI 试衣 / 图片编辑小程序：

```text
用户上传人物图
选择或上传衣服图
填写简单要求
点击生成
等待结果
查看并保存生成图片
```

后端只负责上传 OSS、调用生图 API、保存任务记录和返回结果图。

## 小程序页面

### 1. 首页 / 生成页

这是第一屏，也是核心操作页。

需要包含：

- 人物图选择区
- 服装图选择区
- 生成模式选择
- 提示词输入区
- 生成按钮
- 最近生成结果入口

生成模式先做 4 个：

```text
上衣试穿
下装试穿
整套换装
自定义编辑
```

### 2. 人物图选择

支持两种来源：

```text
上传自己的照片
从模特图库选择
```

建议提示用户：

```text
建议上传清晰、正面、全身或半身照片。
```

### 3. 服装图选择

支持两种来源：

```text
从素材库选择
上传自己的衣服图
```

素材分类：

```text
上衣
裤子
裙子
整套
外套
面料
```

第一版可以先只做：

```text
上衣
裤子
整套
```

### 4. 提示词输入

小程序不要让用户面对复杂 prompt，默认自动生成一句。

默认提示词：

```text
将服装图中的衣服自然地换到人物图中的人物身上，保持人物脸部、姿势、体型、背景和光照尽量不变，保留服装的颜色、纹理、版型和材质细节。
```

用户可以追加要求：

```text
更宽松一点
颜色更浅一点
保留原背景
不要改变脸
增强面料纹理
改成秀场风格
```

后端最终拼接：

```text
系统默认提示词 + 用户追加要求 + 固定保护要求
```

固定保护要求：

```text
不要改变人物身份，不要改变脸部，不要添加多余人物，不要改变主体背景，不要让服装变形。
```

### 5. 生成中页面

点击生成后，不要让请求一直卡住。

流程：

```text
POST /api/generation/try-on
返回 task_id
小程序显示生成中
每 2-3 秒请求 GET /api/tasks/:id
成功后展示结果图
```

页面状态：

```text
排队中
生成中
生成成功
生成失败
```

### 6. 结果页

需要包含：

- 原人物图
- 服装图
- 生成结果图
- 提示词
- 保存到相册
- 再生成一次
- 返回首页

### 7. 我的历史

用户可以查看自己生成过的图片。

列表字段：

```text
结果缩略图
生成模式
创建时间
任务状态
```

详情字段：

```text
人物图
服装图
结果图
提示词
生成参数
```

## 第一版最小闭环

必须先做通：

```text
1. 上传人物图到 OSS
2. 上传服装图到 OSS
3. 创建生成任务
4. 调用生图 API
5. 保存结果图到 OSS
6. 小程序展示结果图
7. 保存历史记录
```

暂时不做：

```text
复杂工作流编辑器
多模型选择
老师本地换色模型
支付
社交分享
复杂权限
```
