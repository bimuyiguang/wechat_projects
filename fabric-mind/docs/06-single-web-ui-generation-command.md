# FabricMind 网页端直接生成 UI 图指令

把下面整段直接复制到网页端生图产品里。  
如果网页端仍然总结方案，就一次只复制“目标”和“画面要求”部分。

```text
请你直接在当前网页端生成一张高保真 UI 参考图片，不要调用本地工具，不要让我下载文件，不要让 Codex 生成图片，不要输出方案，不要分析需求，不要复述项目背景，只在网页端直接生成 UI 图片。

目标：生成一张 FabricMind 微信小程序首页 / AI 试衣生成页 UI 图。

画面比例：9:16 竖屏移动端界面，类似真实微信小程序截图。

产品名称：FabricMind

产品定位：AI 试衣、服装图片生成、素材库选衣、用户上传图片后生成试衣效果。

整体风格：
- 浅色主题
- 高级、干净、真实可开发
- 服装设计 + AI 科技感
- 图片优先
- 像真实微信小程序，不像营销海报
- 不要深色科幻风
- 不要卡通插画
- 不要夸张渐变
- 不要大段说明文字

页面图层和内容要求：

1. 顶部导航层
- 背景为白色或极浅灰
- 左侧显示产品名：FabricMind
- 标题下方可以有一句很短的副标题：AI 试衣生成
- 右上角有一个历史记录图标或文字入口：历史
- 顶部整体高度不要太大，像微信小程序真实页面

2. 主体背景层
- 页面背景为浅灰色，例如 #F6F7F9
- 主体内容使用白色区域或浅色卡片
- 卡片圆角适中，不要过度圆润
- 页面有足够留白，但不要空洞

3. 人物照片上传区域
- 一个大卡片，标题为：人物照片
- 卡片内有一个人物图占位区域
- 占位图可以是时尚模特半身或全身照片预览
- 卡片内有两个操作入口：
  - 上传照片
  - 从模特库选择
- 需要体现这是第一张输入图，类似“图片 A”
- 图片区域要明显，不要只放图标

4. 服装素材选择区域
- 第二个大卡片，标题为：服装素材
- 卡片内有服装图片占位区域，可以展示一件上衣、裤子或整套服装
- 卡片内有两个操作入口：
  - 选择素材
  - 上传衣服
- 需要体现这是第二张输入图，类似“图片 B”
- 服装图片要清楚，像真实素材库图片

5. 生成模式选择层
- 在两张图片区域下方放一个分段选择控件
- 四个选项：
  - 上衣试穿
  - 下装试穿
  - 整套换装
  - 自定义编辑
- 当前选中项可以是“整套换装”
- 分段控件要像真实小程序 UI，不要像网页导航

6. 提示词输入层
- 放一个输入框或文本区域
- 标题为：生成要求
- 输入框默认文字：
  保持脸部和背景不变，让服装自然贴合身体
- 输入框下方可以有 3 个快捷标签：
  - 保留原背景
  - 不改变脸
  - 增强面料纹理
- 这部分要清楚表达：用户可以追加自己的要求

7. 生成按钮层
- 页面底部固定一个醒目的主按钮
- 按钮文字：开始生成
- 按钮颜色可以是黑色、深蓝色或科技蓝
- 按钮宽度接近屏幕宽度
- 按钮下方不要放复杂说明

8. 辅助信息层
- 可以在按钮上方放一句很短的状态提示：
  生成后可在历史记录中查看结果
- 不要出现长篇说明文案

图片内容建议：
- 人物照片区域：时尚模特、清晰正面或半身照片
- 服装素材区域：简洁白底服装图，例如黑色上衣、灰色裤子、整套穿搭
- 页面中不要出现真实品牌 logo
- 不要出现复杂水印

最终图片要求：
- 看起来像可以直接交给前端开发的小程序 UI 设计稿
- 所有中文文字清晰可读
- 页面层级明确
- 上传人物图、上传服装图、选择模式、填写提示词、点击生成这条流程一眼能看懂
- 只生成 UI 图片，不要生成说明文字，不要生成 Markdown，不要生成代码
```
